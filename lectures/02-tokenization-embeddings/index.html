BPE: learn pieces from repetition

Start   l · o · w · e · r
Merge   lo · w · e · r
Merge   low · e · r

Count adjacent pairs → merge the frequent pair → repeat

Simplified intuition for byte-pair encoding (Sennrich et al. 2016).

Try it

A tiny regex tokenizer

import re

pattern = r"\b\w+(?:['’]\w+)?\b|[^\w\s]"

text = "NLP isn't just words—it includes punctuation!"
re.findall(pattern, text)

['NLP', "isn't", 'just', 'words', '—', 'it', 'includes', 'punctuation', '!']

Regex is excellent when you can state the rules. It is not a universal tokenizer.

Let a language library handle the rules

import spacy

nlp = spacy.blank("en")
text = "Don't email support@example.com—visit example.com."

[token.text for token in nlp(text)]

['Do', "n't", 'email', 'support@example.com', '—', 'visit', 'example.com', '.']

spaCy uses general rules plus language-specific exceptions (Explosion 2026).

Ask the model’s own tokenizer

from transformers import AutoTokenizer

tok = AutoTokenizer.from_pretrained("bert-base-uncased")
tok.tokenize("Tokenizers tokenize unseen tokenization!")

['token', '##izer', '##s', 'token', '##ize', 'unseen', 'token', '##ization', '!']

## means “continue the current word” in this WordPiece vocabulary.

From IDs to meaning

Token IDs are addresses—not meaning

king→ 547
queen→ 2938
banana→ 89

Is queen > king?   Is king ≈ banana?

The numbers only identify rows in a table. Their magnitude is arbitrary.

One-hot vectors keep identity…

king[0, 1, 0, 0, 0]
queen[0, 0, 0, 1, 0]
banana[1, 0, 0, 0, 0]

distance(king, queen) = distance(king, banana)

…but says that every different word is equally unrelated.

Embeddings give words coordinates

\[\cos(\theta)=\frac{\mathbf{u}\cdot\mathbf{v}}{\lVert\mathbf{u}\rVert\lVert\mathbf{v}\rVert}\]

Small angle → similar direction → often similar meaning or usage.

The famous analogy

king − man + woman ≈ queen

The vector from man → woman resembles the vector from king → queen.

Powerful illustration—not a law of language. Embeddings also inherit stereotypes and biases from their data.

Ask a pretrained embedding

import gensim.downloader as api

wv = api.load("glove-wiki-gigaword-100")

wv.most_similar("language", topn=5)
