Build the neural language model from that example

Original Figure 1 from Yoshua Bengio, Réjean Ducharme, Pascal Vincent, and Christian Jauvin (2003), “A Neural Probabilistic Language Model,” Journal of Machine Learning Research 3: 1137–1155, p. 1142. Paper and PDF.

This is Bengio et al.’s window-based neural probabilistic language model, shown with the same concrete context from the previous slide.

  • Begin at the left: each discrete word index selects a learned vector from a shared embedding table.
  • Concatenate the vectors for the fixed context window into one vector, \(\mathbf x=(C(w_{t-1}),C(w_{t-2}),\ldots,C(w_{t-n+1}))\).
  • The hidden layer learns distributed features of that context: \(\mathbf a=\tanh(\mathbf d+H\mathbf x)\).
  • The output layer produces one unnormalized log-probability per vocabulary item: \(\mathbf y=\mathbf b+W\mathbf x+U\mathbf a\); softmax normalizes these scores.
  • In the original paper, the embedding parameters and probability network are learned jointly by maximizing the training-corpus log likelihood.
  • The curved dashed route is the paper’s optional direct connection \(W\mathbf x\). When direct connections are disabled, \(W=0\).
  • Emphasize the limitation without developing it yet: this is still a fixed context window. We will decide in the next review how to use that boundary to motivate recurrence.

Why the fixed window cannot scale

IMPROVEMENTS OVER AN N-GRAM LM

✓ No sparsity problem ✓ No table of all observed n-grams

1

The fixed window is too small.

2

Enlarging the window enlarges \(W\).

\[ W\in\mathbb R^{d_h\times kd_e} \quad\Rightarrow\quad |W|=k\,d_h d_e \]

3

No finite window can always be large enough.

4

\(\mathbf x^{(1)}\) and \(\mathbf x^{(2)}\) use different blocks of \(W\): no position symmetry.

We need one neural architecture that can process any-length input without enlarging its parameter matrices.

Adapted from Diyi Yang, “Language Models and Recurrent Neural Networks,” Stanford CS224N/Ling284, Winter 2026, slide 24. Lecture slides.
  • Begin with the two improvements over an n-gram model: learned representations remove the exact-count sparsity problem, and the model does not store a table of observed n-grams.
  • Reveal problem 1: the four-word window discards “proctor,” even if that word is useful for predicting “exams.”
  • Reveal problem 2 and the lower expanded vector together. If the context contains \(k\) embeddings of dimension \(d_e\), the concatenated vector has dimension \(kd_e\). Therefore \(W\) has shape \(d_h\times kd_e\) and gains \(d_h d_e\) parameters for every new position.
  • Reveal problem 3: choosing a larger \(k\) delays the boundary but never removes it.
  • Reveal problem 4: concatenation assigns a separate block of \(W\) to each position. The same word is processed differently in position 1 and position 2; the architecture has no symmetry across time.
  • Final reveal: ask for an architecture whose parameter count is independent of sequence length and whose same transformation can be reused at every position. This is the opening for recurrence; do not show the RNN equation yet.

Recurrent neural networks

A family of neural architectures for sequences

CORE IDEA · Apply the same weights \(W\) repeatedly.

Adapted from Diyi Yang, “Language Models and Recurrent Neural Networks,” Stanford CS224N/Ling284, Winter 2026, slide 25. Lecture slides.
  • Start with one input, one hidden state, and an optional output.
  • Reveal successive time steps. At every reveal, point to the label \(W\) on the horizontal connection.
  • The important change from the fixed-window model is not merely that there are more boxes. It is that every time step uses the same transformation rather than receiving its own position-specific block of a growing matrix.
  • The ellipsis means the sequence can continue without adding a new parameter matrix.
  • Inputs, hidden states, and outputs may have different dimensions; weight sharing means the relevant matrices are reused at every time step.

Can one state preserve useful information through many repeated updates?

RNN formulation and trade-offs adapted from Diyi Yang, “Language Models and Recurrent Neural Networks,” Stanford CS224N/Ling284, Winter 2026, slides 25–27. Lecture slides.

  • Match each arrow to a term in the state update: \(W_x\mathbf x_t\), \(W_h\mathbf h_{t-1}\), and the bias \(\mathbf b_h\).

Backpropagate through one recurrent cell

Forward computation → · gradient flow ←

1 · OUTPUT ERROR

\[ \boldsymbol\delta_z=\hat{\mathbf y}_t-\mathbf y_t \]

2 · REACH THE HIDDEN STATE

\[ \mathbf g_h=U^\top\boldsymbol\delta_z \]

3 · PASS THROUGH TANH

\[ \boldsymbol\delta_a =\mathbf g_h\odot(1-\mathbf h_t^2) \]

4 · FOLLOW BOTH INPUT BRANCHES

\[ \begin{aligned} \nabla_{W_h}L_t&=\boldsymbol\delta_a\mathbf h_{t-1}^{\top}, &\nabla_{\mathbf h_{t-1}}L_t&=W_h^\top\boldsymbol\delta_a\\ \nabla_{W_x}L_t&=\boldsymbol\delta_a\mathbf x_t^{\top}, &\nabla_{\mathbf b_h}L_t&=\boldsymbol\delta_a \end{aligned} \]

Local RNN backpropagation follows the computational graph from softmax cross-entropy through the hidden-state update (Jurafsky and Martin 2026, Ch. 9).
  • Keep the complete forward cell visible, but reveal the backward path one stage at a time. Each numbered gradient overlay on the left is synchronized with the formula carrying the same number on the right.
  • Stage 1: for softmax with cross-entropy, the derivative with respect to the logits is the prediction minus the one-hot target, \(\boldsymbol\delta_z=\hat{\mathbf y}_t-\mathbf y_t\).
  • Stage 2: multiply by \(U^\top\) to move the error from output space into hidden-state space. For this first local derivation, \(\mathbf g_h\) contains only the contribution from the output at time \(t\).
  • Stage 3: differentiate the tanh nonlinearity elementwise. Keep \(\boldsymbol\delta_a\) visible; it is the reusable error signal for every branch entering the cell pre-activation.
  • Stage 4: the same \(\boldsymbol\delta_a\) produces gradients for \(W_h\), \(W_x\), and \(\mathbf b_h\). The branch \(W_h^\top\boldsymbol\delta_a\) sends credit to the previous hidden state.
  • End by pointing to \(\nabla_{\mathbf h_{t-1}}L_t\). We have derived one local backward step; the next slide expands the objective from one output loss to all output losses in the sequence.

When two gradient paths meet, they add

THE FORWARD GRAPH BRANCHES

\(\mathbf h_t\) influences the loss now and the recurrent state next.

PATH 1 · CURRENT OUTPUT

\[ \left.\nabla_{\mathbf h_t}J\right|_{J^{(t)}} =U^\top\boldsymbol\delta_z^{(t)} \]

PATH 2 · FUTURE STATE

\[ \left.\nabla_{\mathbf h_t}J\right|_{\mathbf h_{t+1}} =W_h^\top\boldsymbol\delta_a^{(t+1)} \]

BACKPROPAGATION RULE AT A BRANCH

\[ \nabla_{\mathbf h_t}J =U^\top\boldsymbol\delta_z^{(t)} +W_h^\top\boldsymbol\delta_a^{(t+1)} \]

Every downstream route contributes; the contributions add.

Gradient accumulation at a branching node is the multivariable chain rule applied to the unfolded recurrent computation graph (Goodfellow et al. 2016, Chs. 6 and 10; Jurafsky and Martin 2026, Ch. 9).
  • This slide is the worked answer to the preceding PAUSE question at the level of one hidden state.
  • Read the forward graph first. The state \(\mathbf h_t\) has two downstream uses: it produces the current output and it enters the next recurrent state.
  • Reveal the blue path from \(J^{(t)}\). It contributes \(U^\top\boldsymbol\delta_z^{(t)}\).
  • Reveal the path returning from \(\mathbf h_{t+1}\). It contributes \(W_h^\top\boldsymbol\delta_a^{(t+1)}\).
  • Reveal the plus sign and total gradient. Backpropagation does not choose one route; it sums all downstream contributions at the shared node.
  • This same principle will repeat at every hidden state when the RNN is unfolded through time.

Backpropagation through time

Backpropagation through time is ordinary backpropagation applied to the RNN unfolded as a computation graph (Werbos 1990; Goodfellow et al. 2016, Ch. 10; Jurafsky and Martin 2026, Ch. 9).
  • This slide is intentionally illustration-only. Let the spatial structure carry the explanation.
  • First read the solid teal forward pass: each input updates a hidden state; every hidden state produces a token-level loss; \(W_h\) is reused along the horizontal chain.
  • Reveal the first translucent-blue layer: every loss sends a local gradient into its hidden state.
  • Reveal the second layer: those gradients then travel backward through the recurrent chain, from later states toward earlier states.
  • Reveal the curved paths into the parameter hub: because the same \(W_h\), \(W_x\), and \(U\) were used repeatedly, every time step contributes to the gradients of the same parameter tensors.
  • Final reveal: the curved paths collect every time-step contribution into the shared parameter gradient; sum them, then perform one optimizer update.
  • End with the full backward chain visible. The unresolved question is now how repeated Jacobian products behave when credit must travel across many time steps.

The same chain can erase or amplify credit

The problem is not “recurrence” alone. It is the product of many local transformations: repeated contraction forgets; repeated expansion destabilizes.

Vanishing and exploding gradients in recurrent networks are analyzed through products of Jacobians and their spectral behavior (Bengio et al. 1994; Pascanu et al. 2013).
  • Return to the two scalar cases from the PAUSE slide.
  • Read the upper chain from right to left: \(1\), \(0.6\), \(0.36\), \(0.216\), \(0.1296\). The translucent arrows deliberately fade with the gradient.
  • Read the lower chain: \(1\), \(1.5\), \(2.25\), \(3.375\), \(5.0625\). The orange arrows become more opaque and thicker as the signal grows.
  • Reveal the consequences. A vanishing gradient prevents distant evidence from teaching early recurrent states. An exploding gradient produces unstable parameter updates and can create numerical overflow.
  • Reveal the synthesis last. The scalar example is an intuition pump; in the vector RNN, matrix Jacobians contract or expand different directions at different rates.
  • End with a forward-looking question for the next review: can the architecture create a path along which useful information and gradients travel with less repeated distortion?

Can the recurrent cell create a protected memory path instead of repeatedly rewriting everything?

Global-norm clipping is a practical treatment for exploding gradients, but it does not solve long-term credit assignment (Pascanu et al. 2013; Goodfellow et al. 2016, Ch. 10).
  • Reveal the slide as a practical intervention, not as a new recurrent architecture.
  • Stage 1: after BPTT has accumulated the complete gradient, compute its global Euclidean norm. In the visible example, the norm is \(18\), above the threshold \(\tau=5\).
  • Stage 2: multiply the whole gradient vector by \(5/18\). The new norm is exactly \(5\), but every component is scaled by the same positive factor, so the update direction is preserved.
  • Match the visual shortening on the left to the formula and pseudocode on the right.
  • Stage 3: pass the clipped gradient to the optimizer. Clipping changes the step magnitude only when the norm exceeds the threshold.
  • Reveal the final comparison. Clipping is highly useful for explosions, but it does not make a tiny long-range gradient large again.
  • End on the question about a protected memory path. This creates the need for gated recurrent cells without introducing their equations yet.

  • “2012–2018” is a useful label for the gated-RNN heyday, not the invention period. LSTM dates to 1997 and GRU to 2014.
  • The Transformer arrived in 2017; the transition was gradual and task-dependent, not an overnight replacement.

One recurrent chain: read, then write

The encoder’s final hidden state becomes the decoder’s initial hidden state.

The whole source sentence must pass through one fixed-size vector, c.

The sequence-to-sequence encoder–decoder maps a variable-length source to a variable-length target through a fixed-dimensional state (Sutskever et al. 2014; Cho et al. 2014).
  • Reveal only the blue encoder region first. Follow the French tokens and point out that its state is updated after every input.

  • Reveal the coral decoder region third. It continues recurrent computation, but now produces the English sequence token by token.

Training seq2seq: loss there, credit everywhere

The targets supervise the decoder outputs—then backpropagation trains the entire encoder–decoder chain.

WHERE IS LOSS COMPUTED?Only where target tokens are predicted.

WHAT GETS UPDATED?Decoder parameters, context path, and encoder parameters.

Sequence-to-sequence models are trained end-to-end with target-side token losses and gradients propagated through the full computation graph (Sutskever et al. 2014; Goodfellow et al. 2016, Ch. 10).
  • Reveal the forward computation first. The encoder reads source tokens; the context initializes the decoder; the decoder predicts target tokens.
  • Reveal the four decoder losses. Each prediction is compared with its gold target token using cross-entropy. No separate loss is attached to the encoder states.
  • Sum the token losses into one sequence objective.
  • Reveal the translucent backward path. Although supervision appears on the decoder side, the chain rule carries credit through every decoder state, through c, and back into every encoder state.
  • End with the two-answer synthesis: loss location and parameter-update reach are different questions.
