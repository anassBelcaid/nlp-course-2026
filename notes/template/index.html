1.1 Mathematical typography

A language model assigns a probability to a token sequence. Using the chain rule,

\[ P(w_{1:n}) = \prod_{i=1}^{n} P(w_i \mid w_{1:i-1}). \tag{1}\]

Equation 1 should be readable inline with the surrounding explanation. For a bigram approximation,

\[ P(w_i \mid w_{1:i-1}) \approx P(w_i \mid w_{i-1}). \]

TipIntuition

The chain rule is exact. The approximation appears only when we limit how much history the model may use.

1.2 Code and implementation notes

Code should fit the page, preserve indentation, and remain visually distinct from prose.

from collections import Counter

def unigram_distribution(tokens: list[str]) -> dict[str, float]:
    """Estimate a maximum-likelihood unigram distribution."""
    counts = Counter(tokens)
    total = sum(counts.values())
    return {token: count / total for token, count in counts.items()}
WarningCommon mistake

A maximum-likelihood estimate assigns zero probability to every unseen token. Later notes will introduce smoothing and explicit unknown-token handling.
