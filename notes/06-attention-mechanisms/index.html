Attention Mechanisms

Chapter 6 · Learning where to look

From the encoder bottleneck to soft lookup, cross-attention, self-attention, causal masking, multi-head attention, and the bridge to the Transformer block.
Author

Dr. A. Belcaid

CS 351 · Introduction to Natural Language Processing
Chapter 6 · Attention mechanisms

The recurrent encoder–decoder gave us a general recipe for conditional sequence generation: read an input sequence, compress it into a state, and generate an output sequence. Its central weakness was equally simple: every source detail had to cross one fixed-size vector. Attention repairs this bottleneck by allowing a prediction to retrieve information directly from all available source states.

This chapter develops attention as an inspectable soft lookup. We will keep one small translation example visible while deriving scores, weights, and context vectors; then we will reuse the same mechanism inside a single sequence. The chapter ends at the boundary of the Transformer architecture. We will identify what a complete model still needs, but leave the construction of the Transformer block to the next chapter.

NoteLearning objectives

After this chapter, you should be able to:

  1. explain why one encoder state creates both a storage and an access bottleneck;
  2. calculate attention scores, softmax weights, and a weighted context vector;
  3. distinguish queries, keys, and values by their computational roles;
  4. distinguish cross-attention from self-attention;
  5. derive the matrix form of scaled dot-product attention;
  6. construct and interpret a causal mask;
  7. explain what multiple heads add beyond one attention distribution;
  8. interpret attention visualizations cautiously; and
  9. identify the missing ingredients that motivate a Transformer block.

1 The encoder bottleneck

1.1 Recall: one RNN reads, another writes

Let the source sentence be:

Le colis arrivera demain

and the desired translation be:

The package will arrive tomorrow

An encoder RNN reads the source one token at a time:

\[ h_i=f_{\text{enc}}(h_{i-1},x_i), \qquad i=1,\ldots,n. \tag{1}\]

In the simplest recurrent encoder–decoder, only the final state is passed to the decoder:

\[ c=h_n, \qquad s_0=c. \tag{2}\]

The decoder then produces one target state and token distribution at a time:

\[ s_t=f_{\text{dec}}(s_{t-1},y_{t-1}), \qquad p(y_t\mid y_{<t},x)=\operatorname{softmax}(W_o s_t+b_o). \tag{3}\]

This architecture was historically important: sequence-to-sequence learning showed that a neural model could learn variable-length mappings end to end (Sutskever et al. 2014). The fixed vector, however, forces every source detail—content, order, syntax, entities, and ambiguities—through the same narrow channel.

1.2 The bottleneck is storage and access

The problem is often described as insufficient storage: one vector must remember an entire sentence. That is true, but incomplete. Even if a large vector could store every detail, the decoder would still receive the same undifferentiated vector at every output step.

The decoder should not have to unpack the same vector in the same way for every token. It needs an access mechanism: at step \(t\), form a request that selects the source information useful for that prediction.

ImportantThe change in one sentence

Do not discard \(h_1,\ldots,h_n\). Keep every encoder state available, and let each decoder step retrieve a different weighted combination.

Bahdanau, Cho, and Bengio introduced this learned alignment mechanism for neural machine translation (Bahdanau et al. 2015). Luong, Pham, and Manning later systematized several global and local variants (Luong et al. 2015).

1.3 Section synthesis

The recurrent encoder–decoder compresses because it discards intermediate states. Attention begins with a simple reversal of that decision: preserve the states and learn how to access them.

The next question is computational: how can a model select one memory while remaining differentiable end to end?

2 Attention as soft lookup

2.1 Keep every source memory

After encoding four tokens, retain the matrix of source states:

\[ H= \begin{bmatrix} h_1^\top\\ h_2^\top\\ h_3^\top\\ h_4^\top \end{bmatrix} \in\mathbb{R}^{4\times d_h}. \tag{4}\]

At decoder step \(t\), the previous decoder state \(s_{t-1}\) summarizes what has already been generated. It therefore acts as a request. Informally:

“Given what I have translated so far, which source memory should influence the next word?”

A hard lookup would choose one index \(i\). That discrete choice is awkward to train with ordinary backpropagation. Attention instead performs a soft lookup: assign every memory a nonnegative weight, make the weights sum to one, and retrieve their weighted average.

2.2 Three operations: score, normalize, retrieve

For a query \(q\) and memory pairs \((k_i,v_i)\):

  1. Score each query–key pair:

    \[ e_i=\operatorname{score}(q,k_i). \tag{5}\]

  2. Normalize all scores with softmax:

    \[ \alpha_i=\frac{\exp(e_i)}{\sum_j\exp(e_j)}. \tag{6}\]

  3. Retrieve a weighted combination of values:

    \[ c=\sum_i \alpha_i v_i. \tag{7}\]

The weights satisfy \(\alpha_i\ge0\) and \(\sum_i\alpha_i=1\). The context is therefore a convex combination of values.

ImportantPause · exact calculation

Suppose one query produces the scores

\[ e=[1,3,0,2] \]

for four scalar values

\[ v=[2,5,-1,3]. \]

  1. Calculate \(\alpha=\operatorname{softmax}(e)\).
  2. Calculate \(c=\sum_i\alpha_i v_i\).
  3. Which value contributes most, and why?

TipNumerical stability

Implement softmax after subtracting the maximum score:

\[ \operatorname{softmax}(e)_i = \frac{\exp(e_i-\max_j e_j)}{\sum_k\exp(e_k-\max_j e_j)}. \]

This leaves the probabilities unchanged while preventing unnecessarily large exponentials.

2.4 What learning changes

No human assigns the scores in Table 2. The scoring parameters are trained through the final task loss. If attending to demain helps predict tomorrow, backpropagation adjusts the projections so that similar query–key pairs receive larger scores in future examples.

2.5 Section synthesis

Attention is not a mysterious new memory type. It is a differentiable retrieval rule:

\[ \boxed{\text{score} \rightarrow \text{normalize} \rightarrow \text{retrieve}}. \]

We have not yet specified what the query, keys, and values represent. Cross-attention gives those roles a concrete meaning in translation.

3 Cross-attention

3.1 Queries, keys, and values are roles

In encoder–decoder attention:

A common projected form is

\[ q_t=s_{t-1}W_Q, \qquad k_i=h_iW_K, \qquad v_i=h_iW_V. \tag{8}\]

The key and value originate from the same source state but serve different purposes. A useful analogy is a library:

  • the key is the catalog description used to decide relevance;
  • the value is the book content retrieved after the match.

3.2 Scoring functions

Several differentiable compatibility functions are possible.

3.2.1 Dot product

\[ e_{ti}=q_t^\top k_i. \tag{9}\]

Dot products are efficient and become the standard form in the Transformer.

3.2.2 Additive attention

\[ e_{ti}=v_a^\top\tanh(W_q q_t+W_k k_i+b_a). \tag{10}\]

This small neural network was used in the original alignment model (Bahdanau et al. 2015). Additive and multiplicative variants can learn similar behaviors, but their dimensions, parameter counts, and computational profiles differ (Luong et al. 2015).

3.3 One decoder query creates one alignment

Suppose the decoder is ready to produce tomorrow. Its query is compared with all French source keys:

The context for this decoder step is

\[ c_t=\sum_{i=1}^{4}\alpha_{ti}v_i. \tag{11}\]

The next-token distribution can use both decoder state and retrieved context:

\[ p(y_t\mid y_{<t},x) = \operatorname{softmax}\!\left(W_o[s_t;c_t]+b_o\right). \tag{12}\]

3.4 A new query creates a new alignment

When the decoder moves from package to will arrive to tomorrow, the source keys and values stay fixed, but the query changes. Therefore the attention distribution changes:

\[ \alpha_t = \operatorname{softmax}(q_tK^\top). \tag{13}\]

An attention matrix places one decoder query on each row and one source key on each column. Heatmaps of this matrix can reveal plausible alignments, diffuse uncertainty, repeated coverage, or systematic errors.

WarningAn attention heatmap is evidence—not a proof of reasoning

Weights show how values are mixed at a particular attention operation. They do not, by themselves, establish a complete causal explanation of the model prediction. Alternative weight patterns can sometimes produce similar outputs (Jain and Wallace 2019). Use heatmaps as diagnostic evidence together with interventions, errors, and other analyses.

3.5 Section synthesis

Cross-attention links two sequences:

  • queries come from the decoder;
  • keys and values come from the encoder;
  • each target step retrieves a different source context.

The same lookup can operate without a separate encoder and decoder. If queries, keys, and values all come from one sequence, we obtain self-attention.

4 Self-attention

4.1 Change the origin, keep the mechanism

Cross-attention and self-attention use the same score–normalize–retrieve rule. Only the source of the roles changes.

For an input matrix \(X\in\mathbb{R}^{n\times d_{model}}\),

\[ Q=XW_Q, \qquad K=XW_K, \qquad V=XW_V. \tag{14}\]

The same token vector therefore produces three different learned views: what it asks for, how it advertises itself for matching, and what content it offers if selected.

4.2 A pronoun performs a lookup

Keep the sentence visible:

The animal was tired because it ran.

The token it is ambiguous in isolation. Its query can compare against every key in the sentence. A plausible distribution is:

The contextual output is

\[ z_{it} = .05v_{The}+.55v_{animal}+.05v_{was} +.15v_{tired}+.05v_{because}+.10v_{it}+.05v_{ran}. \tag{15}\]

The output at position 6 is no longer a representation of it alone. It is it interpreted in this sentence.

4.3 Every token asks its own question

Self-attention does not only contextualize the pronoun. Every position \(i\) supplies its own query \(q_i\), produces its own distribution over all keys, and receives its own output \(z_i\):

\[ z_i=\sum_{j=1}^{n}\alpha_{ij}v_j. \tag{16}\]

All \(n^2\) scores can be computed together:

\[ S=QK^\top \in\mathbb{R}^{n\times n}, \tag{17}\]

\[ A=\operatorname{softmax}_{row}(S), \qquad Z=AV. \tag{18}\]

For our seven-token sentence, the dimensions are inspectable:

Row \(i\) of \(A\) contains the weights produced by query \(q_i\). Row \(i\) of \(Z\) is the context retrieved for position \(i\).

4.4 Shorter paths and parallel computation

In a recurrent network, information from position 2 to position 6 crosses four sequential state updates. In one self-attention layer, a learned edge can connect those positions directly.

The quadratic \(n\times n\) score matrix is powerful but can become expensive for very long sequences. This limitation motivates later work on sparse, local, linear, and memory-efficient attention. It does not change the basic lookup derived here.

4.5 Section synthesis

Self-attention creates direct, context-dependent token representations and evaluates all queries in parallel. Two practical questions remain:

  1. Why do dot products become unstable as vector width grows?
  2. How can a language model prevent a position from reading future tokens?

A third modeling question will follow: can one attention distribution capture every useful relation?

5 Modern attention

5.1 Why scale dot products?

Consider a query and key with four matching coordinates:

\[ q=[1,1,1,1], \qquad k=[1,1,1,1]. \]

Their dot product is

\[ q^\top k=1+1+1+1=4. \]

With wider random vectors, more products are summed. Under common independence assumptions, if query and key coordinates have mean zero and variance one, the dot product has variance proportional to \(d_k\):

\[ \operatorname{Var}(q^\top k)=d_k. \]

Dividing by \(\sqrt{d_k}\) restores an approximately unit variance:

\[ \operatorname{Var}\!\left(\frac{q^\top k}{\sqrt{d_k}}\right)\approx1. \]

This matters because large logits make softmax extremely sharp. Probabilities approach zero or one, where useful gradients may become small (Vaswani et al. 2017).

ImportantPause · compare two distributions

Given scores \([4,2,0]\) and \(d_k=4\), compare:

\[ \operatorname{softmax}([4,2,0]) \]

with

\[ \operatorname{softmax}\!\left(\frac{[4,2,0]}{\sqrt4}\right). \]

Which distribution leaves more probability for alternatives?

5.2 Worked scaling example

Since \(\sqrt{d_k}=2\), the scaled scores are \([2,1,0]\).

The complete operator is therefore

\[ \operatorname{Attention}(Q,K,V) = \operatorname{softmax}\!\left( \frac{QK^\top}{\sqrt{d_k}} \right)V. \tag{19}\]

5.3 Causal masking: do not read tomorrow

Suppose an autoregressive language model is trained on:

The animal ran home

At position 3, the task is to predict the next token home from the prefix The animal ran. Unrestricted self-attention would allow the query at position 3 to inspect position 4, leaking the answer.

The causal rule is:

\[ \text{query position }i\text{ may attend to key position }j \quad\text{only if}\quad j\le i. \tag{20}\]

Define an additive mask \(M\):

\[ M_{ij}= \begin{cases} 0, & j\le i,\\ -\infty, & j>i. \end{cases} \tag{21}\]

For four positions:

The masked operation is

\[ \widetilde S = \frac{QK^\top}{\sqrt{d_k}}+M, \]

\[ A=\operatorname{softmax}_{row}(\widetilde S), \qquad Z=AV. \tag{22}\]

Because \(\exp(-\infty)=0\), every forbidden future weight becomes zero. All positions can still be processed in parallel during training; the mask controls information, not execution order.

5.4 Why use multiple heads?

Consider:

The animal did not cross the street because it was wide.

For the token it, several relations may be useful:

  • reference: it \(\rightarrow\) street;
  • description: it \(\rightarrow\) wide;
  • event participants: cross \(\rightarrow\) animal, street.

A single head produces one attention distribution per query. It can mix several signals, but a multi-head layer provides distinct learned projection spaces:

\[ head_r = \operatorname{Attention}(QW_r^Q,KW_r^K,VW_r^V), \tag{23}\]

\[ \operatorname{MultiHead}(Q,K,V) = \operatorname{Concat}(head_1,\ldots,head_h)W^O. \tag{24}\]

The colored linguistic roles are an explanatory possibility, not a constraint. The architecture does not label a head “coreference” or “syntax.” Analyses have nevertheless found heads correlated with positional patterns, delimiters, syntactic dependencies, and coreference (Clark et al. 2019).

5.5 Reading attention visualizations

Two common views are useful.

5.5.1 Attention heatmap

Rows represent queries, columns represent keys, and color intensity represents \(\alpha_{ij}\). A heatmap is effective for inspecting all pairwise weights in one head.

5.5.2 Connection view

Tokens are connected by lines whose opacity or width represents attention strength. This view makes a small number of strong relations visually immediate.

BertViz provides head, model, and neuron-oriented views for Transformer attention (Vig 2019). For a research example connecting heads with linguistic relations, read Clark et al., What Does BERT Look At? (Clark et al. 2019).

WarningInterpret with care

An attractive attention line is not automatically the reason for a prediction. Inspect:

  • several heads and layers, not one selected picture;
  • whether the pattern is stable across examples;
  • how changing or removing attended tokens changes the output;
  • whether value vectors and downstream layers preserve the apparent relation; and
  • whether another attention distribution produces a similar result.

Attention visualization is a valuable microscope, not a complete theory of model reasoning (Jain and Wallace 2019).

5.6 Modern attention in one view

The operator is now stable, information-valid, and able to learn several views. It is still not a complete sequence model.

6 The Transformer bridge

6.1 Self-attention has no order by itself

Compare:

dog bites man
man bites dog

The token set is the same, but the meanings differ. If \(P\) is a permutation matrix that reorders positions, self-attention without positional information is permutation equivariant:

\[ \operatorname{Attn}(PX) = P\operatorname{Attn}(X). \tag{25}\]

Reordering inputs merely reorders outputs. The operation has no independent signal that position 1 came before position 3. A sequence architecture must therefore inject position information. The next chapter will compare ways to do so.

6.2 Attention mixes positions, not features deeply

Attention answers:

Which positions should exchange information?

After that exchange, each token also needs a nonlinear transformation of its features:

How should this position transform the information it received?

The Transformer answers this with a position-wise feed-forward sublayer, but its exact equations and placement belong to the architecture chapter.

6.3 Deep stacks need safe routes

One attention layer creates one round of interaction. Rich models stack many layers, which raises two questions:

  1. Can an original representation survive repeated transformations?
  2. Can activation and gradient scales remain controlled across depth?

Residual pathways and normalization address these requirements in practical Transformer blocks (Vaswani et al. 2017). For now, retain the requirements rather than memorizing a block diagram.

7 Chapter summary

The full conceptual chain is now visible:

  1. A fixed encoder context creates a storage and access bottleneck.
  2. Attention keeps all memories and performs a differentiable soft lookup.
  3. Cross-attention lets each decoder query retrieve a different source context.
  4. Self-attention lets every token retrieve context from its own sequence.
  5. Matrix operations compute all token-to-token scores and weighted sums together.
  6. Scaling controls dot-product magnitude.
  7. Causal masking prevents future-token leakage.
  8. Multiple heads learn parallel projection and retrieval spaces.
  9. Attention still needs order, position-wise transformation, and safe depth to become a full architecture.

The most important reusable formula is:

\[ \boxed{ \operatorname{Attention}(Q,K,V) = \operatorname{softmax}\!\left( \frac{QK^\top}{\sqrt{d_k}}+M \right)V } \tag{26}\]

where \(M=0\) when every connection is permitted and \(M\) is a causal or task-specific mask otherwise.

  • Bahdanau, Cho, and Bengio · Neural Machine Translation by Jointly Learning to Align and Translate introduces learned soft alignment in recurrent encoder–decoder translation (Bahdanau et al. 2015).
